# 架构说明（欧洲动态电价）

## 职责边界

```
┌──────────────────────────────────────────────┐
│  接入层：HTTP / SSE / CLI / OpenAI 兼容桥      │
└───────────────┬──────────────────────────────┘
                │
┌───────────────▼──────────────────────────────┐
│  Agent 层（LangChain v1）                     │
│  - 意图解析：市场/日期/粒度/资产               │
│  - 工具编排                                   │
│  - 技能加载（渐进式披露）                      │
│  - 记忆读写                                   │
│  - 结果解释                                   │
└──────┬───────────────────┬───────────────────┘
       │                   │
┌──────▼──────┐   ┌────────▼─────────┐
│ 数据工具     │   │ 外部预测模型      │
│ Energy-     │   │ TimeGPT (Nixtla) │
│ Charts      │   │ 或自建 FastAPI    │
│ Open-Meteo  │   │                   │
│ ENTSO-E     │   │                   │
└─────────────┘   └──────────────────┘
```

### LLM 该做 / 不该做

| 该做 | 不该做 |
|---|---|
| 理解“明天 DE-LU 电价怎么走” | 直接给出 96 个价格点 |
| 决定先查天气还是先查负荷 | 自己插值/外推 |
| 解释为什么午间负电价 | 编造市场规则 |
| 发现尖峰并触发诊断技能 | 计算结算费用 |
| 生成面向人的报告 | 直接下单/申报 |

## 数据源

| 数据 | 来源 | Key | 说明 |
|---|---|---|---|
| 日前电价 | Energy-Charts v2 `/v2/price` | 不需要 | 聚合 ENTSO-E/EPEX；DE-LU/AT 为 CC BY 4.0 |
| 气象 | Open-Meteo `/v1/forecast` | 不需要 | 温度/风速/辐照/降水 |
| 负荷/风光预测 | ENTSO-E A65/A69 | 需要（免费） | 未配置时降级为 Energy-Charts 实际值代理 |
| 预测模型 | TimeGPT `/v2/forecast` | 需要（30 天试用） | 输出 P10/P50/P90 |

## 两种 Agent 何时用

| | `createAgent` | `createDeepAgent` |
|---|---|---|
| 形态 | 单循环 ReAct | 规划 + 文件系统 + 子 Agent |
| 适合 | 单次预估、规则问答 | 多步研究、长报告、跨数据源核对 |
| 成本 | 低 | 高 |
| 建议 | **默认先用这个** | 确有复杂多步需求再切 |

## 上下文组装顺序

```
system prompt
  + 铁律（数字来源、时区、禁止编造）
  + 用户偏好（市场、资产、风险偏好）
  + 当前时间 / 用户当地日期
  + 历史经验（向量召回 top-k）
  + 技能元数据（name + description）
  + 工具 schema
  ↓
用户消息
  ↓
模型循环：工具调用 → 结果回填 → 继续
```

**知识库内容不预拼**，由模型在循环中调用 `search_market_rules`。

## 中间件规划

| 中间件 | 作用 |
|---|---|
| `summarizationMiddleware` | 长对话自动摘要 |
| `humanInTheLoopMiddleware` | 申报/交易前人工确认 |
| 自定义 `beforeModel` | 按问题裁剪工具、注入市场上下文 |
| 自定义 `wrapToolCall` | 统一超时、重试、埋点 |

## 失败与降级

| 故障 | 处理 |
|---|---|
| TimeGPT 不可用 | 降级到本地季节性基线（`provider=local`），并在回答中标注 |
| Energy-Charts 429 | 进程内缓存 + 指数退避；仍失败则明确报错 |
| ENTSO-E 未配置 | 负荷用实际值代理（`isForecast=false`） |
| 天气 API 失败 | 继续用历史相似日，风险里加一条 |
| 模型输出不合法 | `responseFormat` 校验失败 → 报错，不编造 |

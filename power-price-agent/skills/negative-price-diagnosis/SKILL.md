## 触发条件

满足任一条即触发：

- P50 < 0
- P50 > 历史 95 分位
- 相邻时段价差 > 50%
- 用户明确问「为什么负电价/为什么尖峰」

## 欧洲市场常见原因

按顺序排查，每条都要有数据支撑：

1. **风光大发**
   `get_load_forecast` 看风电/光伏峰值与净负荷低谷是否重合。
   - 德国/丹麦：北海风电 + 午间光伏
   - 西班牙/意大利：午间光伏
   - 北欧：水电 + 风电

2. **负荷低迷**
   看是否周末、节假日、气温温和导致负荷显著低于同期。

3. **跨境输电与阻塞**
   邻区低价电涌入或本地外送受阻会放大价差。
   若数据源没有跨境流信息，明确说明「未获取」。

4. **机组最小出力 / 供热季**
   热电联产在冬季有强制最小出力，会压低电价。

5. **市场规则**
   调用 `search_market_rules` 查报价上下限、负电价处理、偏差考核。

6. **燃料成本**
   煤价/气价（TTF）变化会改变边际机组报价，必要时提示。

## 输出要求

- 先给现象：时段、价格、偏离幅度。
- 再给原因排序：主因 / 次因 / 不确定项。
- 给证据：每个原因对应哪个数据或规则。
- 给风险：是否可能持续、是否影响次日。

## 禁止

- 禁止只用「新能源大发」一句解释所有负电价。
- 禁止在没有规则依据时断言结算方式。
- 禁止忽略「数据未获取」的可能性。
- 禁止把负电价说成系统错误。
